## 发布前核对
- **我没有实测任何一个插件。** 全部功能、命令和局限，来自各仓库的 README（通过搜索和网页抓取读到的）。请你自己装一遍，至少把 kb-rag、deepread、deep-research 三个跑通，再决定要不要保留“怎么装”的命令。
- **dsh 还在开发者预览阶段**，README 明说会有破坏兼容性的改动。命令、参数、版本要求（Node 22.19、dsh 5.5.0 等）可能很快过时，发布前再看一次各仓库的最新 README。
- **官方文档站点和 DeepSeek 的 API 文档，我这边打不开**（当前环境无法访问），所以：dsh 的 API 密钥配置、模型和思考档位的设置，我没有写；DeepSeek V4 的价格我没写具体数字（搜到的来源对 Pro 的价格和优惠截止时间说法不一致）。如果你想写，请查官方定价页。
- 第十节“Anthropic 兼容接口地址 `https://api.deepseek.com/anthropic`”“OpenCode 用 /connect 接入”：来自搜索结果的摘要，我没有打开原页面核对。
