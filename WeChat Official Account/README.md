读者：大陆研究生。内容：AI 教程 + 研究生科研。简体中文。

## 这一版怎么写的

你让我参考宝玉（JimLiu）的 skill。我读了他的 baoyu-skills 仓库，先说结论：**里面没有专门的“写文章”skill**，和写作直接相关的是下面几个，我把它们的规则搬过来用了：

| 来源 | 我用到的规则 |
|---|---|
| baoyu-format-markdown | 文章带 frontmatter：title、slug、summary（一句话，50–80 字）、description（2–3 句，100–200 字）、coverImage；标题进 frontmatter，正文不再放 H1；标题用 8 种钩子公式（颠覆认知、解决方案、悬念、具体数字、反差、结果先行、问句、共鸣）加 1–2 个直白标题，4–5 个候选；标题约 30 字，前 5 个字就要有信息差，能具体就不抽象，否定优于肯定，不要标题党；正文别过度格式化：加粗只留给读者会划线的句子，列表只在结构明显时用，小标题要具体 |
| baoyu-translate | “重写而不是翻译”，读起来要像中文原生写的；顺着中文语序，长句拆短；术语第一次出现时括号注明原文；默认 storytelling 的叙述感 |
| baoyu-article-illustrator | 先分析文章，决定哪里需要配图；每张图有类型（infographic / scene / flowchart / comparison / framework / timeline）、风格（默认 sketch-notes）和配色（macaron 等）；提示词按 ZONES / LABELS / COLORS / STYLE / ASPECT 写，LABELS 用文章里的真实词；人物只画简化剪影；颜色名不能作为文字出现在图里 |
| baoyu-cover-image | 封面五个维度：type、palette、rendering、text、mood；标题文字只用原标题，不许编；留白 40%–60% |
| baoyu-post-to-wechat | 发布时读 frontmatter 里的 title、summary、author、coverImage；封面默认找 imgs/cover.png；图片用相对路径 |

文章里能看到的变化：frontmatter、`imgs/` 目录、`NN-类型-名字.png` 的图片命名、按 ZONES/LABELS/COLORS/STYLE/ASPECT 写的提示词，以及更短的句子、更少的加粗。

## 文件夹结构

```
0X-文章名/
├─ article.md       正文（带 frontmatter，直接粘进 WeMD）
├─ 发布备忘.md       标题备选、封面提示词、配图大纲、发布前要核对的事实
└─ imgs/            截图（已生成）；AI 生图和真实截图需要你放进来
```

如果 WeMD 把文章开头的 `---` 区块当成正文显示，删掉那一段 frontmatter 就行；标题和摘要在 `发布备忘.md` 里也有。

## 配图规则

1. **AI 生图**：文中凡是写着【AI 生图提示词】的引用块，就是需要你自己生成的图。提示词写在图的位置，包含类型、风格、画幅和要存的文件名。生成后按文件名放进 `imgs/`，删掉引用块。封面提示词在各篇的 `发布备忘.md` 里。
2. **能用代码模拟的界面**：由 `_工具/截图源文件/*.html` 渲染成截图，已放进 `imgs/`，图上或文中已注明是示意或演示数据。
3. **真实软件的界面**：第 04 篇是真实商业软件，我看不到它的界面，不模拟，留了【截图占位】让你自己截。

重新渲染截图：`python3 _工具/render_screenshots.py`（需要 Chrome 和 Pillow）。第 03 篇的图表由 `_工具/make_chart.py` 生成。上传到图床后想批量换链接，用 `_工具/replace_image_urls.py`（用法见脚本开头）。
