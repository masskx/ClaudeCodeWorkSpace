## 为什么换了这一批(以及我不能保证的事)

上一版选题偏“工具介绍”，没有情绪钩子，你不满意是对的。这一版的选择依据：

1. **你自己的爆款规律**：你发过的题目都是“读者焦虑 / 痛点 + 一个具体的、现在就能用的东西”。这版每篇都按这个结构写。
2. **真实的研究生焦虑**：搜索到的讨论集中在三类 —— AI 带来的规则焦虑(会不会被误判、能不能用)、研一落差(听不懂组会、读不动文献)、AI 依赖与能力成长的矛盾。01、02、06 对应前者和后者，03 对应研一落差。
3. **时效性**：01、04 利用的是今年 ICLR 评审里 AI 审稿、论文假引用被曝光这两个公开话题。

**我没法保证哪篇会火。** 我拿不到公众号后台数据，也没找到“研究生 + AI 方向”的可信阅读量统计(搜到的“10 万+ 方法论”多是营销内容)。建议先发 01 和 04 测试反应，再根据你的后台数据调整。

## 关于 WeMD 图床：我能做到的和做不到的

**做不到的：直接帮你把图片上传到 WeMD 的图床。** 原因有两个：

- 当前环境访问不到 wemd.app(我测试过，域名都解析不了)。
- 从 WeMD 的项目页看，它的图床是**你在 WeMD 里配置后，由你的浏览器/应用去上传**(支持官方图床、七牛、阿里云 OSS、腾讯云 COS、S3 兼容)，没有公开的上传接口，也没有看到命令行用法。官方图床的免费空间据说还比较紧张。
- WeMD 的“批量上传本地图片”和“微信官方图床”，在它的 GitHub issue #109 里只看到作者说已在一个**尚未确认合并**的 PR 里实现，**不能当成已经可用**。

**已经替你做好的**：

1. 每篇文章的图片都已生成好，放在各自的 `images/` 里，`article.md` 里用相对路径引用(`images/fig1.png`)。
2. `_工具/replace_image_urls.py`：你把图片上传到图床、拿到链接后，把链接写进一个 json，运行它就会生成 `article_公众号版.md`，里面的图片路径已换成线上链接，直接整篇粘进 WeMD。

**推荐的实际流程**：

1. 打开 WeMD，把 `article.md` 的内容粘进去，预览排版。
2. 在 WeMD 里把 `images/fig1.png` 上传(按你配置的图床)，得到链接；或者直接在 WeMD 编辑器里拖入图片，让它自动替换。
3. 点 WeMD 的“一键复制”，粘进公众号后台。封面图 `cover.png` 在后台单独上传。
4. 如果图片很多，想批量替换：用 `replace_image_urls.py`，用法见脚本开头的注释。

如果你愿意提供自己的图床(例如自己的阿里云 OSS / 腾讯云 COS / GitHub 仓库图床)，**不要把密钥发在聊天里**；告诉我你选的是哪一种，我可以帮你写一个本地上传脚本，密钥由你放在自己电脑的环境变量里。
