Kimi 平台提供了基于 OpenClaw 的 Kimi Claw,宣称用户可在浏览器内一键部署常驻智能体,无需服务器、终端或 Docker。同时 GitHub 上的 Claude Code + OpenClaw + Codex 中文教程热度很高(数千 star),说明 OpenClaw 在中文社区关注度大。

■ 文章大纲
1. 钩子:你是不是也被“先装环境”这四个字劝退过?
2. 先讲清概念:什么是常驻智能体,和普通聊天机器人有何不同。
3. 一步步演示:浏览器里开通 → 配置 → 第一次对话。
4. 三个科研向用法:
   ① 每天自动整理指定关键词的新论文摘要
   ② 帮你盯着会议 / 期刊截稿日期
   ③ 汇总课题组周报
5. 安全提示:不要把账号密码、未发表数据交给智能体。
6. 成本与限制:实测后如实写。
