# 项目说明

## 课题
小样本场景下 XX 模型的泛化能力。

## 目录
- data/raw/       原始数据，不要修改、不要删除
- data/processed/ 预处理结果，可以重新生成
- src/            代码
- results/        实验结果和图
- 实验日志.md      每次实验的设置和结果

## 运行
训练  python src/train.py --config configs/base.yaml
评测  python src/eval.py

## 规矩
1. 不动 data/raw/ 里的任何文件
2. 不要编造实验结果、数据和参考文献
3. 改动比较大的时候，先说方案，等我点头
4. 跑完实验，把设置和结果追加到 实验日志.md
5. 不要引入新的第三方库，要加先问我
